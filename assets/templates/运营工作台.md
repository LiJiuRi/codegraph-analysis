# 运营工作台（portal 示例）

运营日常操作的页面清单：每页是什么功能、背后对应哪个业务域。本章是全书的业务入口索引。

| 页面 | 功能 | 对应业务域 |
|---|---|---|
| 账单列表 | 按客户/车牌/状态筛选账单，批量导出 | 账单核心 |
| 发起结算 | 对选中账单一次性结清 | 结算 |
| 发票管理 | 查开票进度、重开发票 | 发票 |
| 财务推送查询 | 查推送集团财务系统的结果，失败重推 | 财务对接 |
| 报表导出 | 按周期导出业务报表 | 导出 |

（页面名取自前端路由的中文名称；页面 ↔ 业务域映射是全书导航的入口。）
